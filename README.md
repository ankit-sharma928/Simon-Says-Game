# Simon Says Game
A fun and interactive memory-based game built using HTML, CSS and JavaScript.
Test your memory skills by repeating the sequence of colours shown by the game!

# Live Demo
[Play Simon Says Game](https://ankit-sharma928.github.io/Simon-Says-Game/)

# How To Play
1. Press any key to begin the game.
2. The game will highlight a colour.
3. Repeat the sequence by clicking the correct buttons.
4. With each level, a new colour is added to the sequence.
5. if you click the wrong colour, the game ends.
